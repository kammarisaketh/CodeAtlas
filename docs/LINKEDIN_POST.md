# LinkedIn Post Draft

I built CodeAtlas, a full-stack iOS portfolio project for AI-powered codebase understanding.

CodeAtlas helps engineers connect a GitHub repository, index the source code, explore the architecture, ask questions about the codebase, and review code quality risks from a native iOS app.

What I built:

- Native SwiftUI iOS app
- MVVM-style architecture
- Sign in with Apple
- Secure Keychain token storage
- GitHub OAuth connection
- FastAPI backend
- Repository indexing flow
- Code review and repository Q&A screens
- Account, settings, and privacy flows
- API, architecture, security, and product documentation

The goal was to build something closer to a real engineering product than a tutorial app: clean UI, clear architecture, backend integration, and a practical developer workflow.

This project helped me practice iOS engineering, backend architecture, authentication, repository processing, and AI-ready product design.

GitHub: https://github.com/kammarisaketh/CodeAtlas
