# CodeAtlas Screenshot Guide

Use these screenshots for GitHub, LinkedIn, and portfolio pages.

## Required Screenshots

Capture these iPhone screenshots in both light mode and dark mode if possible:

1. **Home Dashboard**
   - Shows product name, main actions, and repository health.

2. **Repository Dashboard**
   - Shows connected repositories, indexing status, and action buttons.

3. **Add Repository**
   - Shows the `owner/repo` input and GitHub connection context.

4. **Architecture Explorer**
   - Shows repository folders/files and selected file details.

5. **Ask Your Code**
   - Shows a repository question and answer.

6. **AI Code Review**
   - Shows review findings, risk labels, and suggested improvements.

7. **Account**
   - Shows Apple login status, GitHub connection, app version, and health score.

## How To Take Screenshots In Simulator

1. Run CodeAtlas in Xcode.
2. In the Simulator menu, choose **File > New Screenshot**.
3. Rename each screenshot clearly:

```text
01-home.png
02-repositories.png
03-add-repository.png
04-explore.png
05-ask.png
06-review.png
07-account.png
```

4. Save screenshots into:

```text
docs/screenshots/
```

## LinkedIn Image Recommendation

For LinkedIn, use a 3-image carousel:

1. Home Dashboard
2. Repository Explorer
3. AI Code Review

Keep captions short and focused on what the app does.
