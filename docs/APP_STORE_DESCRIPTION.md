# App Store Description Draft

## Name

CodeAtlas

## Subtitle

Understand codebases faster

## Short Description

CodeAtlas helps software engineers explore, review, and understand repositories from a native iOS app.

## Full Description

CodeAtlas is a code intelligence app built for engineers who work with unfamiliar or complex repositories.

Connect a GitHub repository, index the project, and use CodeAtlas to explore the architecture, inspect files, ask focused questions, and review code quality risks. The app is designed for repository-aware answers instead of generic AI chat.

Use CodeAtlas to:

- Understand how a repository is organized
- Find where important features are implemented
- Review code for reliability, security, performance, and maintainability issues
- Browse indexed files and architecture structure
- Ask questions about authentication, configuration, data flow, dependencies, and risky changes
- Keep account and repository actions in one clean developer-focused workspace

CodeAtlas is designed with a native Apple-style interface, dark mode support, clear navigation, and professional developer workflows.

## Feature Highlights

- GitHub repository connection
- Repository indexing
- Architecture explorer
- AI-style code review
- Repository question answering
- Account and privacy controls
- Secure token storage
- Native SwiftUI experience

## Privacy Summary

CodeAtlas is designed to treat repository content as private and sensitive. Tokens are stored securely, local secrets are not committed to source control, and repository access is handled through GitHub authorization.
