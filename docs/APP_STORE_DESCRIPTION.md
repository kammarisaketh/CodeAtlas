# App Store Description Draft

CodeAtlas helps software engineers understand unfamiliar codebases faster.

Connect a repository, index the project, and ask focused questions about implementation details, architecture, dependencies, configuration, and change impact. CodeAtlas answers using repository evidence and links every important claim back to files and line ranges.

Features:
- Repository-aware AI answers
- File and line citations
- Codebase search
- Source-code navigation
- Saved answers and notes
- Private-by-design repository handling

CodeAtlas is built for professional developers who need precise codebase memory, not generic chat.
