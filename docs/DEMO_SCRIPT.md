# CodeAtlas Demo Script

Use this script for a short portfolio video, LinkedIn clip, or GitHub demo GIF.

## 60-Second Demo

### 1. Opening

Show the CodeAtlas app icon and launch screen.

Say:

> CodeAtlas is an iOS app that helps engineers understand and review unfamiliar codebases.

### 2. Login

Show Continue with Apple or Continue with Mock Session.

Say:

> The app supports Apple authentication and secure token storage. For demos, I can also use a mock session.

### 3. GitHub Connection

Open Account and show GitHub connected.

Say:

> CodeAtlas connects to GitHub through OAuth, so users can choose repositories they are allowed to access.

### 4. Repository Dashboard

Open Repos and show a repository card.

Say:

> After adding a repository, the backend indexes the source files and tracks repository status.

### 5. Architecture Explorer

Open Explore and tap a file.

Say:

> The Explore tab lets users browse the repository structure and inspect indexed files.

### 6. Ask Your Code

Open Ask and ask:

```text
Where is authentication implemented?
```

Say:

> Instead of a generic chatbot, CodeAtlas answers questions using the indexed repository context.

### 7. Code Review

Open Review and show findings.

Say:

> CodeAtlas can review indexed code for maintainability, reliability, performance, and security issues.

### 8. Closing

Show the Account or Home screen.

Say:

> This project demonstrates SwiftUI, MVVM architecture, Apple authentication, GitHub OAuth, FastAPI, repository indexing, and AI-ready backend design.

## Demo Checklist

- Backend is running at `http://127.0.0.1:8000`.
- iOS app builds successfully.
- Apple login or mock session works.
- GitHub shows connected.
- At least one repository is added.
- Repository indexing completes.
- Explore, Ask, Review, Repos, and Account tabs open without crashes.
